# Самоосуществлятор целей — бот

Telegram-бот, который платно проверяет формулировки целей по рамке через
Claude API. Оплата — Telegram Stars. Есть личный кабинет, бесплатный
мануал и админка прямо в Telegram.

## Как это работает

- **/check** — прислал цель целиком → получил разбор.
- **/step** — пошаговый диалог, разбор по пунктам один за другим.
- **1 кредит = 100 ⭐ = 5 попыток** разобрать одну цель до конца.
- Если бот подтвердил, что цель прошла рамку полностью — цикл закрывается,
  а неиспользованные попытки из этого кредита сгорают (не переносятся на
  новую цель).
- Если 5 попыток закончились без успеха — цикл тоже закрывается, нужен
  новый кредит.
- Ошибка на стороне Anthropic (сбой API) — попытка НЕ списывается.
- 0 кредитов — бот жёстко останавливается и показывает кнопку оплаты.
- `/manual` — бесплатная выдача PDF-мануала, кредит не тратит.
- `/support` — контакт для спорных ситуаций и возвратов.

## 1. Получить токены

1. Токен бота — у [@BotFather](https://t.me/BotFather): `/newbot`.
2. API-ключ Anthropic — на [console.anthropic.com](https://console.anthropic.com)
   (Settings → API Keys). Платный API, нужна карта и баланс.
3. Свой Telegram ID — у [@userinfobot](https://t.me/userinfobot). Это
   единственный ID, у которого будет доступ к админ-командам.

## 2. Настройка Telegram Stars

Оплата звёздами встроена в Bot API — отдельно ничего регистрировать не
нужно. Если `send_invoice` с `currency="XTR"` вернёт ошибку — проверь
настройки платежей у @BotFather (`/mybots` → выбрать бота → Payments).

## 3. Локальный запуск

```bash
cd goalbot
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# впиши TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, OWNER_TELEGRAM_ID

python bot.py
```

При первом запуске автоматически создастся файл `goalbot.db` (SQLite) —
в нём хранятся пользователи, балансы и история запросов.

## 4. Деплой на Railway

1. Залей папку `goalbot` в репозиторий на GitHub.
2. На [railway.app](https://railway.app) → New Project → Deploy from
   GitHub repo → выбери репозиторий.
3. Railway сам поставит зависимости по `requirements.txt`.
4. В Settings → Variables впиши те же переменные, что в `.env`.
5. Deploy — бот работает 24/7.

**Важно:** SQLite-файл на Railway живёт в контейнере — при пересборке
деплоя (redeploy) данные могут теряться, если не подключить постоянный
volume (Railway → Settings → Volumes). Для старта с небольшим числом
пользователей это не критично, но при росте стоит подключить volume
или перейти на внешнюю БД (Postgres, который Railway тоже предоставляет).

## 5. Админ-команды (только твой Telegram ID)

- `/admin` — общая статистика (пользователи, кредиты, выручка в Stars).
- `/recent` — последние 15 запросов к боту.
- `/topusers` — список пользователей и их балансов.
- `/userhistory <telegram_id>` — история конкретного пользователя.
- `/setbalance <telegram_id> <число>` — вручную выставить баланс
  (для возвратов, бонусов, исправления ошибок).

## 6. Ограничения текущей версии

- История пошагового диалога (`/step`) хранится в памяти процесса
  (`step_histories` в `bot.py`) — при перезапуске бота незавершённые
  диалоги обнуляются. Баланс и кредиты при этом не теряются (они в БД).
- Оплата пока только через Telegram Stars. Tribute (карта/крипта) —
  следующий этап, потребует отдельный веб-сервер с HTTPS для приёма
  вебхуков и домен.
- Модель по умолчанию — `claude-haiku-4-5-20251001`, меняется через
  `CLAUDE_MODEL` в `.env`.

## 7. Структура проекта

```
goalbot/
├── bot.py              # хендлеры, FSM, платежи, админка, точка входа
├── db.py                # SQLite: пользователи, кредиты, история, статистика
├── claude_client.py      # обёртка над Anthropic API
├── prompts.py             # системный промпт + все тексты бота
├── config.py               # загрузка .env
├── manual.pdf               # бесплатный мануал, раздаётся через /manual
├── requirements.txt
└── .env.example
```
